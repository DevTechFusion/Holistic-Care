Agent Dashboard Total Incentive Permission Test

Test Overview

This test demonstrates the permission system for the Agent Dashboard API's total_incentive field.

The total_incentive field will only be included in API responses if the authenticated user has the total_incentive permission for the AgentDashboard module.

Permission Details

Permission Name: total_incentive

Module: AgentDashboard

Display Name: View Total Incentive

Assigned Roles: agent, managerly, super_admin

Authentication

Test Range

API Response

Test Instructions

  1. Login with a user account that has the total_incentive permission (agent, managerly, or super_admin role)
  2. Copy the Bearer token from the login response
  3. Paste the token in the "Bearer Token" field above
  4. Select a time range (daily, weekly, monthly, yearly)
  5. Optionally enter a department ID to filter results
  6. Click "Test Agent Dashboard" or use the range buttons
  7. Check if the response includes the total_incentive field in the cards object

Expected Behavior:

  • With Permission: Response should include "total_incentive": 45.50 (or similar value) in the cards object
  • Without Permission: Response should NOT include the total_incentive field in the cards object

API Endpoint:

GET /api/agent/dashboard?range={range}&department_id={id}
