Pharmacy Total Incentive Permission Test

Test Overview

This test demonstrates the new permission system for the Pharmacy API's total_incentive field.

The total_incentive field will only be included in API responses if the authenticated user has the total_incentive permission for the Pharmacy module.

Permission Details

Permission Name: total_incentive

Module: Pharmacy

Display Name: View Total Incentive

Assigned Roles: agent, managerly, super_admin

Authentication

API Response

Test Instructions

  1. Login with a user account that has the total_incentive permission (agent, managerly, or super_admin role)
  2. Copy the Bearer token from the login response
  3. Paste the token in the "Bearer Token" field above
  4. Click "Test Pharmacy API with Permission Check"
  5. Check if the response includes the total_incentive field

Expected Behavior:

  • With Permission: Response should include "total_incentive": "1250.50" (or similar value)
  • Without Permission: Response should NOT include the total_incentive field
